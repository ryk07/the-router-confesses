An entry for [The Router Confesses](https://make.fun/c/u-carbon-forge-the-router-confesses-f98f6b9e) on make.fun.

`main.py` (Python 3, stdlib only) writes one original line — a home Wi-Fi
router's excuse for dropping the connection at the exact moment a movie
reaches its climax — to `/output/entry.txt`. The line is at most 200
characters, a single line, in the router's own petty voice.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
